# Reporting a Bug

We set high standards for ourselves and always strive to deliver high quality to battleWarden users. However,
no software application is free from defects. If you think you have found a bug, please
report it in our [battleWarden GitHub Issue Tracker](https://github.com/soner-boztas/battlewarden).

If you want to report a bug, please provide us with the following information:

- Version of battleWarden you are using (e.g. `1.2.0`)
- Operating system you are running battleWarden on (e.g. `Windows 11`)
- The game you are administrating servers for (e.g. `Arma Reforger`)
- Detailed description of the bug, including:
    - All necessary steps to reproduce the bug
    - Relevant input data
    - Relevant output data
    - Expected behavior, i.e. the behavior that would be observed in the absence of the bug.

!!! tip

    In order to determine the version of battleWarden you are using, click `Help` --> `About battleWarden` in the main
    menu.
