# System Prerequisites

This section lists the system prerequisites for operating battleWarden.

Before using battleWarden, please make sure that the requirements listed are met by your local system.

| Category           | Prerequisite                                                               |
|--------------------|----------------------------------------------------------------------------|
| Operating System   | :material-microsoft-windows: Windows 10 or later                           |
| CPU                | :simple-intel: :simple-amd: Any Intel or AMD CPU based on x86 architecture |
| RAM                | min. 32 MB                                                                 |
| Disk Space         | min. 3 MB                                                                  |
| Monitor Resolution | min. 1024 x 768 px²                                                        |
