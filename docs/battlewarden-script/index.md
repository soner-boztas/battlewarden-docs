# battleWarden&colon;Script

battleWarden:Script is a built-in module providing a scripting interface for advanced users of battleWarden. Using
this module, you can get full control of battleWarden giving you unlimited possibilities. Manipulating the GUI, advanced
control over your game servers and IO operations are just a few features supported by the scripting interface. The
underlying scripting language is *battleScript* and can be considered as a lightweight, fast and easy-to-use embeddable
scripting library for games and applications.
