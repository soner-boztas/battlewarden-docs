# Frequently Asked Questions

??? question "Are there any costs associated with using battleWarden?"

    No! battleWarden is free to use.

??? question "How do I receive updates for battleWarden"

    In order to get the latest updates for battleWarden, please refer to the
    [Downloads page](https://battlewarden.net/downloads/) or start the integrated online updater from within
    battleWarden.

??? question "Which games are supported by battleWarden"

    battleWarden supports all games powered by the anti-cheat engine [BattlEye] including:

    - Arma Reforger
    - DayZ SA
    - ArmA 3
    - ArmA 2

    In order to be able to use battleWarden please make sure to configure [BattlEye] on your server.

??? question "Which operating systems are supported by battleWarden"

    At the current time the following operating systems are supported:

    - Windows 11
    - Windows 10
