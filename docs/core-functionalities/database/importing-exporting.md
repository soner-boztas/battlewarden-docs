# Importing/Exporting

By following the instructions below you can import and export existing databases in battleWarden.

## Importing a Database

In order to import an existing database from your local file system, click `Database` --> `Import...` in the
[Main Menu Bar].

## Exporting a Database

If you want to export your database, click `Database` --> `Export...` in the [Main Menu Bar].
The exported file can be imported by battleWarden or by any other software application being capable of
importing [SQLite] database files.

[Main Menu Bar]: ../basic/overview-main-application-window.md
