# Features

battleWarden supports various powerful features for productive administration of Arma (including Arma Reforger) and
DayZ servers. Below you will find a brief list highlighting the most important features:

- [x] Full support of Arma Reforger, Arma 2 / 3 and DayZ (SA) game servers with [BattlEye] enabled
- [x] Own proprietary, fully functional [BattlEye] client technology being more robust and faster than any other
  available clients
- [x] No runtime environments required (such as .NET)
- [x] Intuitive, modern and fully DPI aware graphical user interface
- [x] Built-in server manager
- [x] User kicking and banning functionality
- [x] Local player database (based on SQLite) to keep a record of what is going on your game servers
- [x] Access to the player chat
- [x] Viewing administrators connected to your server
- [x] Server logs (part of the battleWarden:Spy module)
- [x] Triggers and custom actions (part of the battleWarden:Spy module)
- [x] Scripting interface (part of the battleWarden:Spy module)
- [x] Simple command-line interface
