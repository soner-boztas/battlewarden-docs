# Installation

In order to install battleWarden on your system follow these steps:

1. Download the ZIP archive containing the latest version of battleWarden from the
   [Download page](https://battlewarden.net/downloads/)[^1].
2. Once downloaded, extract the contents of the ZIP archive into an empty folder on your local file system.

!!! info

    In order to launch battleWarden, run the `battleWarden.exe` executable.

## Update

An online update package is included in the ZIP archive, which will update your battleWarden installation to the latest
version. Just launch the `Update.exe` executable.

[^1]: Releases of battleWarden are always deployed to [GitHub](https://github.com/soner-boztas/battlewarden).
