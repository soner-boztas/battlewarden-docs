# Introduction

battleWarden is a remote control (RCon) software application designed for administrators of ArmA and DayZ game servers.
Whether you’re running a public or a private community server, battleWarden offers powerful functionalities to help you
monitor, manage and secure your servers efficiently.

battleWarden is built on top of the popular anti-cheat solution [BattlEye] and comes with its own proprietary, blazing
fast client technology supporting all capabilities of the
[BattlEye remote control protocol](https://www.battleye.com/downloads/BERConProtocol.txt).
